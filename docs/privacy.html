1. Who this policy covers

DevCreator ("the application") is a private, self-hosted command-line tool that produces original animated short films and publishes them to a single YouTube channel owned by its sole operator. It is not a hosted service and is not offered to other people. It has no user accounts and no sign-up.

The application has exactly one user: its operator, who is also the owner of the YouTube channel it publishes to. It authenticates only to that operator's own Google account and accesses only data belonging to that account.

2. Use of YouTube API Services

This application uses YouTube API Services. By using it, the operator agrees to be bound by the YouTube Terms of Service.

Google's handling of data received through these APIs is governed by the Google Privacy Policy.

3. What data the application accesses

CategorySpecificsSource
Authorisation credentials An OAuth 2.0 access token and refresh token for the operator's own Google account. Granted scopes: youtube.upload, youtube.readonly, youtube.force-ssl, yt-analytics.readonly. Google OAuth consent, granted by the operator
Own-video counters View count, like count and comment count for videos the application itself published to the operator's channel. YouTube Data API — videos.list
Own-channel performance data Aggregate metrics only: views, estimated minutes watched, average view duration and percentage, likes, dislikes, comment and share counts, subscribers gained and lost, traffic-source categories, and an audience-retention curve. YouTube Analytics API — reports.query
Public topic research Publicly listed titles and metadata of existing videos, used only to avoid producing a story that duplicates one that already exists. YouTube Data API — search.list

What the application does not access

It does not access, request, collect or store any personal information about viewers or about any person other than the operator. It does not read viewer identities, individual watch histories, subscriber lists, private messages, or comment authors' account details. The performance data described above is aggregate and contains no individual viewer records. The application holds no data belonging to any third party's Google account.

4. How data is stored

All data stays on the operator's own computer. Nothing is transmitted to a server operated by the application, because no such server exists.

WhatWhereProtection
OAuth tokensA single local file, config/youtube_token.json File permissions 0600 — readable only by the operator's OS account. Never written to logs or to the database.
Video counters and channel analyticsA local SQLite database file Stored on the operator's own disk, not published or transmitted.

5. How data is used

Retrieved performance data is used for one purpose: to inform which story topics the operator's own channel produces next. It is not used to build profiles of any person, is not used for advertising, and is not combined with data from any other source about any individual.

6. Data sharing

Data obtained from YouTube API Services is not sold, rented, traded, or shared with any third party under any circumstances. It is not transferred to advertisers, data brokers, or analytics providers.

The application does use third-party providers to generate story text and artwork — these receive only prompts describing fictional animal characters and story situations written by the application. No data obtained from YouTube API Services is ever sent to them.

7. Data retention and deletion

Data obtained from YouTube API Services is retained only while it remains useful for choosing future topics, and is deleted whenever the operator chooses. Because all storage is local, deletion is immediate and complete:

  • Deleting the local database file permanently removes all stored counters and analytics.
  • Deleting config/youtube_token.json permanently removes the stored authorisation credentials and ends the application's access.
  • The application stores no backups off the operator's machine, so no copy survives elsewhere.

When authorisation is revoked (see section 8), the application immediately loses all access to YouTube API Services, and any data previously retrieved is deleted from local storage.

8. Revoking access

The operator may revoke this application's access to their Google account at any time, without notice and without contacting anyone, through the Google security settings page:

https://myaccount.google.com/permissions

Select the application in the list of third-party apps with account access and choose Remove Access. Revocation takes effect immediately and permanently invalidates the stored refresh token.

9. This website

This site is a set of static pages. It sets no cookies, runs no analytics or tracking, serves no advertising, and collects no information from visitors.

Any change to this policy will be published on this page with an updated date at the top.
